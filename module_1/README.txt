JHU Software Concepts Website
=============================

Run the site on Windows
-----------------------

1. Start the Flask website from the `module_1` directory:

    python run.py

2. Open the site in a browser:

    http://localhost:8080/

Available pages
---------------

    Home:     http://localhost:8080/
    Projects: http://localhost:8080/projects
    Contact:  http://localhost:8080/contact

Stop the site
-------------

Return to the PowerShell window running Flask and press Ctrl+C.
